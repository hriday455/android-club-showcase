# 🤖 Android Club — Official Showcase Website

A clean, modern, and lightweight showcase website created for **Android Club**. Designed with an attractive dark-mode tech aesthetic, an ambient background, interactive project filtering, an FAQ accordion, and a recruitment form.

---

## 🌟 Features Implemented

1. **Attractive Tech Background**: Modern dark tech theme with subtle background artwork, glowing Android Robot green accents (`#3DDC84`), and frosted glass cards.
2. **Hero / Welcome Section**: Club tagline, catchy headline, live recruitment badge, quick action buttons, a 3D smartphone mockup, and key club statistics.
3. **About Us Section**: Clear explanation of what the club does with 4 core pillars (Workshops, Apps, Hackathons, Mentorship).
4. **Learning Tracks**: Breakdown of club domains (Native Kotlin & Jetpack Compose, Flutter, Material 3 UI/UX, Backend).
5. **Projects Showcase**: Interactive category filters (*All*, *Jetpack Compose*, *Flutter*, *Hackathons*) with direct GitHub repo links.
6. **Events & Workshops**: Cards for upcoming bootcamps and annual hackathons with registration buttons.
7. **Team Section**: Core leads with photos, roles, and short bios.
8. **Recruitment Application Form**: Clean input fields with domain selection and real-time submission confirmation.
9. **FAQ Accordion**: Interactive collapsible drawer for common questions.
10. **Lightweight & Easy Code**: Pure semantic HTML5, clean CSS3, and simple vanilla JavaScript with zero external frameworks or complex dependencies.

## 🚀 How to Run in VS Code

### Step 1: Open Folder in VS Code
1. Open **Visual Studio Code**.
2. Click **File → Open Folder...** and select the `android-club-showcase` folder.

### Step 2: Run with Live Server (Recommended)
1. Install the **Live Server** extension if you haven't already:
   - Press `Ctrl + Shift + X` to open Extensions.
   - Search for **"Live Server"** (by *Ritwick Dey*) and click **Install**.
2. Right-click on `index.html` in the file tree on the left.
3. Select **"Open with Live Server"** (or click **"Go Live"** at the bottom right corner).
4. Your browser will automatically open:
   ```text
   http://127.0.0.1:5500/index.html
   ```

### Alternative: Direct Double Click
You can also open the project folder in Windows File Explorer and **double-click `index.html`** to view the website directly in Chrome, Edge, or Firefox!
