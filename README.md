# Android Club Showcase Website

A responsive showcase website built for the campus Android Club, featuring club tracks, events, projects, recruitment information, and an FAQ section.

🔗 **Live Website:** [https://hriday455.github.io/android-club-showcase/](https://hriday455.github.io/android-club-showcase/)

---

## 📱 Features

- **Hero & Overview:** Introduction to the club with key stats and quick action links.
- **Learning Tracks:** Breakdown of domains (Jetpack Compose, Flutter, UI/UX, Backend).
- **Projects Showcase:** Interactive category filter for club-built projects.
- **Events & Workshops:** Information on upcoming bootcamps and hackathons.
- **Recruitment Form:** Interactive application form for prospective members.
- **FAQ Section:** Collapsible accordion for common questions.
- **Responsive Design:** Dark-themed UI optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **HTML5** (Semantic layout)
- **CSS3** (Flexbox, CSS Grid, Custom Properties, Media Queries)
- **Vanilla JavaScript** (DOM manipulation, event filtering, form handling)
